# --- einat-ebpf：锁定的 NAT 实现（全锥形必需）---
#     包定义在 ebpf/einat-ebpf（预编译二进制包，理由见 §13.14），
#     DEPENDS 里的 @(x86_64||aarch64) 正好覆盖 x86 与 RK/IPQ60xx。
#     本行把它装进镜像；服务**默认开启**（/etc/config/einat enabled='1'）。
#     开启后它会给 fw4 发 procd data 把 masquerade 关掉，所以配套加了自证：
#     einat.init 的 einat_verify 在把 masquerade-off 交给 fw4 之后盯着 WAN 的
#     TCX link（bpftool link show，TCX 不出现在 tc filter show 里），超时没出现
#     就 stop 掉服务、让 fw4 的 masquerade 回来。否则「eBPF NAT 没起来 +
#     fw4 已被通知别做 NAT」= LAN 直接没有 NAT。
#     注意 verify 里**故意不写 uci**：一次瞬时失败不该永久关掉数据面。
#     要回退到 fw4 masquerade：uci set einat.config.enabled='0' && uci commit
#     einat && /etc/init.d/einat stop && /etc/init.d/firewall reload
CONFIG_PACKAGE_einat-ebpf=y
